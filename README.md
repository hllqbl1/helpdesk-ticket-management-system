# Helpdesk Ticket Management System

A fullstack web application for managing helpdesk tickets.

## Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- React Router

### Backend

- Golang
- net/http
- MySQL

## Features

- Create helpdesk tickets
- View ticket dashboard
- View ticket details
- Admin dashboard
- Manage tickets
- Update ticket priority and status
- Delete tickets
- Contact page

## Project Structure

- frontend: React application
- backend: Golang REST API

## Installation

### Backend

1. Open the backend directory.
2. Copy `.env.example` to `.env`.
3. Configure your MySQL credentials.
4. Install dependencies:

   go mod tidy

5. Run the backend:

   go run main.go

### Frontend

1. Open the frontend directory.
2. Install dependencies:

   npm install

3. Run the development server:

   npm run dev
